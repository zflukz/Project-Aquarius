# KMUTT Gazebo Harmonic world

Generated by Unity menu **KMUTT > Build Map**. Same origin and scale as the Unity scene.
**Default world of the simulator** (`PX4_GZ_WORLD=kmutt`): the `px4-sim` image copies `models/` and `worlds/`
into PX4's `Tools/simulation/gz/` (compose build context `simulation`, see `docker/px4-sim/Dockerfile`).

- Area: 10 x 10 km centred on KMUTT Bang Mod (13.6513, 100.4944); 2 x 2 km detailed core
- Axes: x = east, y = north, z = up (metres). Unity (x, y, z) = Gazebo (x, z, y)
- Terrain height range: -1.883 .. 8.288 m
- Models: kmutt_terrain (heightmap + satellite, sharp core ground), kmutt_city (buildings, roads, water), kmutt_trees (core, visual only)

## Edits after the Unity export (needed for PX4 SITL — redo them after a re-export)

| File | Change | Why |
| :--- | :--- | :--- |
| `worlds/kmutt.sdf` | no `<plugin>` tags; physics 4 ms / 250 Hz | a world with plugins makes Gazebo skip PX4's `server.config` → no IMU / baro / mag / camera systems → PX4 never gets sensor data |
| `worlds/kmutt.sdf` | sun `cast_shadows` false | CPU rendering (no GPU): 1 drone camera RTF 0.33 → 0.99 |
| `models/kmutt_terrain/model.sdf` | height offset `-1.883` on the link pose, heightmap `<pos>` 0 | Gazebo's physics (dartsim) ignores heightmap `<pos>` → collision ground was 1.883 m above the visible ground |
| `models/kmutt_terrain/model.sdf` | `core.obj` also as collision | heightmap cells are 9.8 m and up to 0.2 m below the visible core ground |
| `models/kmutt_city/model.sdf` | roads visual only | thin road meshes ~5 cm above the ground flipped a spawning drone |
| `meshes/core.obj`, `trees.obj` | vertex normals added: `python3 tools/add_obj_normals.py models/*/meshes/*.obj` | meshes without normals render flat white in Gazebo |

Better: let the Unity exporter write normals and these SDF settings directly.

## In the simulator

- Drones spawn at x = -65, y = -53 + 3·i, z = 7.5 (open ground SW of the campus pond; drone 0 home ≈ 13.65082,
  100.49380). The world origin itself is **in the pond** (water is visual only). Override: `DRONE_SPAWN_X/Y/Z`.
- Trees are off by default (`KMUTT_TREES=1` turns them on): 2 drone cameras, idle RTF 0.88 without, 0.46 with.
- Buildings near home: ~13 m within 30 m, ~20 m within 60 m, ~39 m at 100 m, ~47 m within 200 m above the
  ground → default mission altitude is 40 m (`ALT`); raise it for areas further away.

## Run standalone (Ubuntu / WSL2 with Gazebo Harmonic, without PX4)

```bash
cd Simulation
export GZ_SIM_RESOURCE_PATH=$PWD/models:$GZ_SIM_RESOURCE_PATH
gz sim worlds/kmutt.sdf     # no plugins in the world -> Gazebo's default systems (physics, scene, user commands)
```
