# KMUTT Gazebo Harmonic world

Generated by Unity menu **KMUTT > Build Map**. Same origin and scale as the Unity scene.

- Area: 10 x 10 km centred on KMUTT Bang Mod (13.6513, 100.4944); 2 x 2 km detailed core
- Axes: x = east, y = north, z = up (metres). Unity (x, y, z) = Gazebo (x, z, y)
- Terrain height range: -1.883 .. 8.288 m
- Spawn height at campus centre: about z = 5.051
- Models: kmutt_terrain (heightmap + satellite, sharp core ground), kmutt_city (buildings, roads, water), kmutt_trees (core, visual only)

## Run (Ubuntu / WSL2 with Gazebo Harmonic)

```bash
cd GazeboExport
export GZ_SIM_RESOURCE_PATH=$PWD/models:$GZ_SIM_RESOURCE_PATH
gz sim worlds/kmutt.sdf
```
